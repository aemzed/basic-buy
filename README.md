Small e-commerce demo app — product listing, cart, checkout, login, and an admin panel.

## Stack
React · TypeScript · Vite · shadcn/ui · Tailwind · Supabase

## Run locally
```bash
npm install
npm run dev
```

Needs Supabase credentials for auth/data — see `src/integrations/supabase`.
